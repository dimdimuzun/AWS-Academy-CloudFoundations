## Глобальна інфраструктура AWS

### AWS Regions (Регіони AWS)
- Регіон AWS — це географічна область.
- Реплікація даних між регіонами контролюється користувачем.
- Комуникація між регіонами використовує внутрішню мережу AWS.
- Кожен регіон забезпечує повну надмірність та підключення до мережі.
- Регіон зазвичай складається з двох або більше зон доступності.
- **Приклад:** Регіон Лондон (London Region)

---

### Вибір регіону
- Вимоги до управління даними та юридичні обмеження
- Протягненість до клієнтів (латентність)
- Вибір регіону для ваших сервісів, додатків та даних залежить від:
  - Доступних сервісів у регіоні
  - Вартості (може варіюватися між регіонами)

---

### Зони доступності (Availability Zones)
- Кожен регіон містить кілька зон доступності.
- Кожна зона доступності — це ізольована частина інфраструктури AWS.
- Зони доступності складаються з окремих дата-центерів.
- Вони спроектовані для ізоляції помилок.
- Зони з’єднані через високоскорісні приватні мережі.
- Ви обираєте зони доступності.
- AWS рекомендує реплікувати дані та ресурси між зонами для надійності.

---

### Дата-центри AWS
- Дата-центри AWS спроектовані для забезпечення безпеки.
- Вони забезпечують надмірність та високу надійність.
- У середньому, кожен дата-центр містить більше 10 000 серверів.

---

## Категорії сервісів AWS

### Приклади категорій:
1. **Безпека, ідентифікація, комплаєнс (Security, Identity, & Compliance)**
   - **IAM (Identity and Access Management)** — глобальний сервіс.
2. **Мережі та доставка контенту (Networking & Content Delivery)**
   - **Amazon VPC** — рівень регіону.
   - **Amazon CloudFront** — використовує точки розподілу (edge locations) для зниження латентності.
3. **Обчислення (Compute)**
   - **Amazon EC2** — рівень регіону.
4. **Функції (Lambda)**
   - **AWS Lambda** — рівень регіону.

## Перевірка знань

### Приклад запитання на іспиті
**Який компонент глобальної інфраструктури AWS використовує Amazon CloudFront для забезпечення низької латентності?**

**Варіанти відповіді:**
- A. AWS Regions
- B. AWS edge locations
- C. AWS Availability Zones
- D. Amazon Virtual Private Cloud (Amazon VPC)

**Правильна відповідь:** B  
**Пояснення:** Ключові слова у запитанні: компонент глобальної інфраструктури AWS, CloudFront, низька латентність.
